# Raw samples

Real responses from each source, saved unmodified by `npm run fetch:sources`, one folder per source id (e.g. `hdx.cod-ab-tha/package_show.json`, `dopa.villages/excerpt.json`, `osm.geofabrik/state.txt`). Adapters are written and tested against these files.

This folder is empty: the Phase 1 build environment could not reach the source hosts (see DATA_SOURCES.md). No synthetic or demo data is stored here.
